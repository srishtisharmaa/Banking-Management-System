# Banking Management System Using Java

A menu-driven Java 17 console application demonstrating customer/account management, deposits, withdrawals, transfers, transaction history, exception handling and concurrent deposits.

## Requirements
- JDK 17+
- Maven 3.8+

## Run
```bash
mvn clean compile
mvn exec:java
```

## Demo accounts
- `1001001` — Savings account, opening balance ₹5,000
- `2002001` — Current account, opening balance ₹10,000, overdraft limit ₹2,000

## Project contents
- `src/main/java` — application source
- `docs/project-report.md` — complete project report
- `docs/class-diagram.png` — rendered class diagram
- `docs/class-diagram.puml` — editable PlantUML diagram
- `sample-output` — representative console output
